# Changelog

All notable changes to this project will be documented here.

## [0.1.0] - 2026-08-19

### Added

- Local stdio MCP server based on the TypeScript MCP SDK 2.x.
- Lazy Playwright Chromium session with public-network policy and heavy-asset blocking.
- Compact `text`, sanitized `dom`, and computed-style `visual` page views.
- Stable `e` action refs and `img` image refs.
- Unified interaction tool with an automatic post-action snapshot.
- Explicit on-demand image retrieval with size and MIME validation.
- Unit, Chromium integration, browser-session, and MCP protocol tests.
- Reproducible browser MCP benchmark with token, latency, transfer, and image-delivery measurements.
- English benchmark report and GitHub-native token-usage chart.
